Article: [Beginner's guide to GitHub: Creating a pull request](https://github.blog/developer-skills/github/beginners-guide-to-github-creating-a-pull-request/)


I chose this article because I am learning how to use GitHub for this assignment. The idea that a change can be discussed before it becomes part of a project is interesting to me. A pull request gives other people a chance to inspect the changes and suggest improvements.

I also found the advice about keeping pull requests small useful. A focused change seems easier to understand and review than several unrelated changes combined together. This makes me think that good collaboration depends on explaining a change clearly, as well as writing the change itself.
